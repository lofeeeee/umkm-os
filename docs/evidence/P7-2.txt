Artefak
- crates/infrastructure/src/billing_repo.rs  usage: anggota aktif, undangan tertunda, produk non-archived, total byte
  file, percakapan bulan ini (agregat P6-6, tidak berkurang saat purge), token AI platform bulan ini (WIB).
- apps/api/src/billing.rs  over_limit (403 reason=plan_limit + limit + max), expired (403 reason=
  subscription_expired), require_operational, check_count; GET subscription kini memuat usage.
- Titik penegakan (batas dibaca dari plans.limits_json setiap permintaan):
  - produk: POST /tenants/{t}/products (max_products);
  - anggota: POST /tenants/{t}/invitations (anggota aktif + undangan tertunda ≤ max_members);
  - file: POST /tenants/{t}/uploads (total byte + file baru ≤ storage_bytes);
  - percakapan: POST /public/chat/conversations (conversations_monthly);
  - AI: runtime — token platform = min(batas paket, kuota operator); BYOK hanya bila byok_allowed; paket tak
    terbaca → kuota 0 (fail-closed) → quota_exceeded tanpa memanggil provider.
  - langganan habis (uji coba/periode lewat): /public/site, /public/products(/slug), /public/categories,
    /public/checkout-config, /public/checkout, chat start/messages → 403 subscription_expired; chat config enabled
    = false. Dashboard tetap dapat dibuka (kelola & bayar).
- frontend: pesan batas paket & langganan habis di dashboard (describe), situs publik "Toko sedang tidak aktif".
- Test lama yang memerlukan AI platform / > 2 anggota memakai helper pro() (Pro aktif): ai_http, audit_http,
  chat_http, conversation_staff_http, team_http, ai_runtime — konsekuensi keputusan: uji coba = batas Starter
  (0 token AI platform).

Catatan
