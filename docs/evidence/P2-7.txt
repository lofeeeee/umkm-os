Temuan
- *.localhost TIDAK bisa dipakai untuk dashboard lokal: tanpa entri Public Suffix List, Chromium menganggap
  app.localhost dan api.localhost site berbeda -> cookie sesi SameSite=Lax dari fetch lintas site ditolak
  (login "berhasil" 200 tetapi sesi kosong). Produksi aman: my.id ada di PSL sehingga app.ryasai.my.id dan
  api.ryasai.my.id satu site (ryasai.my.id). Lokal memakai umkm.test (config/development.toml CORS +
  --host-resolver-rules Playwright). Didokumentasikan di README dan .env.example.
- Layout desktop rusak di screenshot pertama: kelas section `s s-hero`/`s-contact` sama dengan kelas blok
  di dalamnya -> seluruh section menjadi grid 2 kolom / flex. Diperbaiki (modifier `s--{type}`, kolom gambar
  hanya bila ada gambar) + tes regresi "kelas section tidak bertabrakan".
- Spesifikasi e2e awalnya saling bergantung (spesifikasi editor mengganti judul yang dicari spesifikasi
  responsif); kini responsif membandingkan h1 dengan data API, editor memakai judul bermarkup.
