## Temuan: tes flaky P1-2 (rate_limit_window_expires...)
Saat 'cargo test --workspace' diulang 3x, 1 run gagal: 'window harus kedaluwarsa' (window 800ms, sleep 1000ms). Expiry Redis memakai jam dinding server; di WSL2 jam dapat dikoreksi di bawah beban, jadi tes berbasis sleep lintas proses rapuh.
Perbaikan: tes diganti menjadi asersi TTL deterministik (PTTL = window setelah percobaan pertama, tidak bertambah pada percobaan berikut, reset saat key hilang).
