P9-5 — <head> situs toko per Host, robots.txt, sitemap.xml, JSON-LD, favicon (ADR-0018) — 2026-11-13T22:09:21+07:00

Rancangan
- apps/api/src/site_head.rs: GET /api/v1/public/document?path=/… → site.html (shell build frontend) dengan
  <title>, meta description, canonical, og:* (title/description/url/site_name/type/locale/image), twitter:card,
  <link rel=icon>, dan JSON-LD (LocalBusiness di beranda; Product + Offer IDR di /produk/{slug}).
  Sumber: versi TERBIT (seo.title/description/image/favicon) + profil bisnis; draf tidak pernah dipakai.
  Gambar = signed URL absolut (api_public_origin) hanya untuk aset milik tenant (signed_assets).
  Langganan nonaktif/tanpa profil → shell apa adanya. Host tak dikenal/fitur nonaktif → 404.
- GET /api/v1/public/robots.txt (Sitemap per Host; Disallow keranjang/akun/pesanan) dan /sitemap.xml
  (beranda + ≤500 produk aktif). Semua Cache-Control public, max-age=60; Vary: Host.
- Keamanan: escape HTML untuk teks & atribut; JSON-LD di-escape untuk konteks <script> (<,>,& → \u003c…),
  sehingga teks pemilik toko tidak bisa menutup elemen. path disaring [A-Za-z0-9/_-] (lainnya → "/"),
  Host disaring. JSON-LD adalah blok data (tidak dieksekusi) → tidak terkena script-src CSP.
- Konfigurasi [site] (shell_path, api_public_origin dengan <ROOT_DOMAIN>, scheme); dev = nonaktif.
  Dockerfile: image api menyalin /fe/out/site.html dari stage frontend-build yang sama dengan image web;
  compose memberi build-arg PUBLIC_API_ORIGIN yang sama ke keduanya agar hash chunk identik.
- Caddy: /robots.txt & /sitemap.xml → API; path tanpa ekstensi (GET/HEAD) → /api/v1/public/document;
  respons 4xx/5xx API → shell statis (situs tetap tampil tanpa meta). Cookie dibuang (header_up -Cookie).
